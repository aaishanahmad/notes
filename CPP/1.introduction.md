### Features of c++
- c++ is a middle level langauge
- c++ supports principles of object oriented paradigm.
- c++ joins three seprate programing traditions
	1. the procedural lanuage tradition represented by c.
	2. the object-oriented lanuage tradition , represented by the class enhancements c++ add to c.
	3. generic programming , supported by c++ templates.
### Comparison between c and c++
- c++ is super set of c language
- c++ program can use existing c software libraries like stdio.h  and so we can use printf scanf etc
- c++ libraries = c libraries + other libraries
- c follows top down approach of programming , c++ follows down up approach of programming.
- c adopts procedure oriented programming , c++ adopt object oriented programming.
