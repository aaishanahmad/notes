### Address of operator
- & is known as address of operator 
- It is an unary operator 
- operand must be the name of variable
- & operator gives address number of variable
- & is also known as reference operatoe in c
### Indirection operator
- * is  indirection operator
- It is also known as dereferencing operator
- It is an unary operator
- It takes address as an argument and return the content/container whose address is its argument

### **Pointer Arthmetic**
Operation allowed on pointers or address:
- increment/decrement of a pointer.
- we can add or substract integer to/from an address.
	- pointer + n = pointer + size of(type of pointer) * n
	- pointer - n = pointer - sizeof (type of pointer) * n
- Subtracting two pointer of the same type 
	- gives  diffrence in no of block in between the type of pointer 
- Comparison of pointer of the same type
