### **Conditional Statements
- **1 if**
  ```c
 if (condition)
 {
 //code
 }
  ``` 

- **2. if-else**
```c
if (condition)
{
//code
}
else (condition)
{
//code for else
}
```
- **3. if-else ladder**
```c
if (condition 1)
{
//code 
}
else if (condition 2)
{
//code if condition1 false and condition 2 true
}
else {
//code for else
}
```
- **4. switch**
```c
switch (variable)
{
case 1:/* code when  variable==1*/ break;
case 2 : /*code */ break;
default : 
}
```
- **5.Conduitional operator / ternary operator
```c
condition ? expression1: expression2
//run expression 1 if condition true else expression2 
//example 1
x = a>b ? a : b
//expample 2
a>b ? printf("a is greater "): printf("b is grater");


```
