### Compiler vs Interpreter
- **Compiler :** A compiler is a software that transforms source code written in a programming language into another computer language .
![[Screenshot From 2026-11-09 17-34-51.png]]
- **Cross Compiler :** if the compiled program can run on a computer whose CPU or operating system is different from the one on which the compiler runs, the compiler is known as a cross compiler.
- **Decompiler :** A program that translate form a low level language to higher level one is a decompiler.
- **Transpiler :** A program that translates between high-level lanuage is usually called source to source compiler or tranpiler.
- **Interpreter :** It translate source code line by line and send for inmmediate execution (one line at a time)
![[Screenshot From 2026-11-09 17-43-30.png]]
- **Just in time compiler :** It has mixed features of interpreter and compiler. it interprets code line by line and send for execution (like interpreter) but when platform is busy in execution instruction , JIT interpreters next lines and stores them somewhere in the memory (like compiler).![[Screenshot From 2026-11-09 17-48-21.png]]
